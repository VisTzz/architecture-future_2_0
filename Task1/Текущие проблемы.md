| **Проблема**                              | **Описание**                                                                                   | **Критичность** |
|-------------------------------------------|-----------------------------------------------------------------------------------------------|-----------------|
| 1. Медленное построение отчётов           | Большие объёмы данных (сотни терабайт) и сложные трансформации замедляют процесс анализа.      | Высокая         |
| 2. Устаревшие технологии                  | Использование Microsoft SQL Server 2008 и PowerBuilder не соответствует современным требованиям. | Высокая         |
| 3. Отсутствие единого хранилища данных    | Данные разбросаны по разным системам, что усложняет их интеграцию и управление.                | Высокая         |
| 4. Низкая масштабируемость                | Текущая архитектура не справляется с ростом данных и новых бизнес-направлений.                | Высокая         |
| 5. Сложность поддержки                    | Большое количество бизнес-логики в SQL-сервере затрудняет поддержку и развитие системы.         | Средняя         |
| 6. Ограниченная гибкость                  | Текущая система не поддерживает быстрое добавление новых источников данных или доменов.        | Средняя         |
| 7. Проблемы с безопасностью               | Отсутствие централизованного управления правами доступа к данным.                              | Средняя         |
| 8. Низкая производительность ETL/ELT      | Процессы загрузки, трансформации и агрегации данных занимают много времени.                    | Высокая         |
| 9. Отсутствие самообслуживания            | Бизнес-пользователи зависят от IT-отдела для создания отчётов и анализа данных.                 | Высокая         |
| 10. Отсутствие data lineage               | Нет возможности отслеживать происхождение данных и их изменения.                               | Средняя         |
